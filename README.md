
# Crater Clash

Crater Clash is an original browser-based artillery battle game inspired by classic turn-based tank games.

## Features

* Destructible terrain
* Wind, angle, and power controls
* Multiple weapons
* Sound effects
* Online multiplayer rooms
* Gamertags
* Lobby system
* Projectile replay
* Scoreboard and PIN profiles
* Shareable room links

## Tech Stack

* HTML
* CSS
* JavaScript
* GitHub Pages
* Supabase Realtime
* Supabase Postgres
